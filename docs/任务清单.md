## 1. 选课经常"服务器内部错误"(500) ✅ 已修复

**根因确认**：是 TiDB Serverless 瞬时抖动（连接重置/坏包/握手超时，ADR-6 已知问题）。`db.js` 的 `query()` 有自动重试，但 **`withTransaction()` 事务封装没有**——选课/退课是事务写操作，撞上抖动就直接 500。线上实测 500 频率和"每次操作序列的第一个写请求"高度相关（冷连接）。

**修复**：`withTransaction` 补齐同款瞬时错误重试（换新连接、最多 2 次、递增退避；业务错误码不重试）。要求业务幂等——选课(upsert 重激活)/退课天然满足。

## 2. 登录后刷新跳回登录页 ✅ 已修复

**根因**：刷新令牌轮换是**两步非原子写库**——先作废旧 refreshToken，再落库新 refreshToken。中间任何一步撞上 TiDB 瞬时 500，旧令牌已作废、新令牌没保存 → 客户端 refreshToken 永久失效 → 之后每次 F5 刷新必失败 → 静默跳登录页（严重时触发重放保护吊销全部会话）。与问题 1 同源（线上抖动频繁），所以"经常"掉线。

**修复**：
- 后端 `auth.js` 新增 `rotateRefreshTokenAtomic()`：同一行**原位换 hash** 的事务轮换，任一步失败整体回滚，旧令牌保持有效可直接重试
- 前端 `tryRefresh()` 对瞬时 50000 退避重试 3 次；只有令牌真失效(40100)才放弃
