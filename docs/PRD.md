# PRD · 产品需求文档

## 1. 项目名称

**智汇校园 —— 一站式智慧校园服务平台**

- 论文题目（备选）：《基于 EdgeOne 边缘全栈架构的"智汇校园"综合服务平台的设计与实现》
- Slogan：智慧汇聚于校园
- 仓库建议名：`zhihui-campus`

## 2. 目标用户与角色

| 角色 | 说明 | 主要入口 |
|---|---|---|
| 学生 | 日常使用全部学生侧功能 | 小程序 / H5 |
| 教师 | 课务、成绩、审核类操作 | Web 管理端 |
| 后勤/宿管 | 宿舍分配、报修处理 | Web 管理端 |
| 管理员 | 全局配置、用户与权限管理 | Web 管理端 |

## 3. 功能清单与优先级

### P0 核心模块（70% 精力，做深做透）

1. **统一登录与权限**：单点登录、JWT、RBAC（学生/教师/后勤/管理员）
2. **学生管理**：学籍信息、班级、成绩录入与查询
3. **智能选课**：选课/退课、**时间冲突检测**、名额并发扣减（乐观锁）、个人课表
4. **图书借阅**：馆藏查询、借书/还书、逾期计算、预约
5. **宿舍管理**：楼栋/房间管理、分配、调宿、**报修工单流转**（提交→受理→完成→评价）

### P1 扩展模块（保证能跑，标准 CRUD + 简单状态机）

6. **社团管理**：社团信息、活动发布、报名
7. **校园点餐**：菜单、购物车、订单（模拟支付）、取餐码
8. **二手交易**：商品发布（图片）、浏览、求购、站内联系
9. **失物招领**：失物/招领发布（图片）、状态流转、认领确认
10. **健身打卡**：每日打卡、连续天数（KV 计数）、排行榜

### P2 加分项（有余力才做）

11. 数据可视化大屏：活跃度、订单量、借阅量统计
12. 消息通知：站内信、逾期/工单提醒

## 4. 不做清单（防止烂尾，答辩也要能主动说明）

- ❌ 真实支付（点餐为模拟支付 + 订单状态流转）
- ❌ 微服务 / SpringCloud（单体分层即可，本项目为 Node Functions）
- ❌ 自训练 AI 模型（如做识别功能一律调现成 API）
- ❌ 真实短信/公众号推送（站内信即可）

## 5. 验收标准

- Web 管理端可登录，四种角色看到不同菜单
- 小程序端完成：选课、借阅查询、点餐下单、二手发布、失物发布、打卡
- 选课并发场景演示不超名额（可用脚本模拟并发验证）
- 全流程可演示、可讲解数据库设计
