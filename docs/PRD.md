# PRD · 产品需求文档

## 1. 项目名称

**智汇校园 —— 一站式智慧校园服务平台**

- 论文题目（2026-09-16 定稿）：《基于云边协同与 Serverless 架构的"智汇校园"一站式服务平台设计与实现》
- Slogan：智慧汇聚于校园
- 仓库：`zhihui-campus` → https://campus.keaidang.com/

## 2. 目标用户与角色（2026-09-17 定稿：五角色 RBAC）

| 角色 | 定位 | 主要入口 |
|---|---|---|
| 学生 | 服务消费者：选课、成绩、请销假、报修等 | 门户 → 工作台（学院蓝主题） |
| 教师 | 教学执行者：开课、成绩录入、公告 | Web 工作台（青绿） |
| 辅导员 | 院系学生事务管理：审批、本院数据 | Web 工作台（琥珀） |
| 校领导 | 全局数据**只读**决策者 | Web 工作台（靛紫，M4 驾驶舱） |
| 超管 | 系统运维：用户/角色/权限独占 | Web 工作台（红） |

## 3. 功能清单与优先级（2026-09-17 与调研架构对齐，见 RESEARCH-功能架构调研.md）

### 一期（P0，已上线 2026-09-17）

1. **统一登录与权限**：SSO、JWT 双令牌、RBAC 五角色 + 数据范围三层防线 ✅
2. **用户管理**：账号/角色/启停/归属院系班级（超管 + 辅导员本院视角）✅
3. **M1 教务线**：智能选课（名额并发扣减防超卖）、个人课表、成绩查询与录入 ✅
4. **M2 学工线**：请销假审批流闭环（两表引擎）、宿舍报修工单、公告（全校/院系定向）✅
5. **门户**：服务卡片 SSO 联动（redirect 原路跳回）+ 角色主题化工作台 ✅

### 二期（P1，已上线 2026-09-20）

6. **图书借阅**：馆藏查询、借书/还书、逾期计算（schema-009，/library）✅
7. **失物招领 / 社团活动 / 校园论坛**（原二手集市决策改为论坛，含交易板块）：标准 CRUD + 状态机 + 图片上传（blob 暂存）✅
   - 附带：忘记密码双通道（管理员重置 + 邮箱验证码自助找回）、图片 blob 上传组件 ✅

### P2 加分项（未开始）

8. **M4 校领导驾驶舱**：全校运行态势只读大屏（活跃度、选课热度、工单时效统计）
9. 消息通知：站内信、审批结果提醒
10. uni-app 小程序端（H5 + 微信小程序）

## 4. 不做清单（防止烂尾，答辩也要能主动说明）

- ❌ **校园点餐**（2026-09-17 决策砍掉：涉及支付链路，毕设做"预订不支付"易显半成品）
- ❌ 真实支付
- ❌ 微服务 / SpringCloud（单体分层即可，本项目为 Node Functions）
- ❌ 自训练 AI 模型（如做识别功能一律调现成 API）
- ❌ 真实短信/公众号推送（站内信即可）
- ❌ 健身打卡（优先级让位给 M3/M4，KV 计数方案已记录可随时启用）

## 5. 验收标准（更新于 2026-09-20）

- [x] 请销假全流程闭环（申请→审批→销假，审批流两表留痕）
